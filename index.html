05

대중교통 예상 이동시간

후보 역 이름 또는 지도 마커를 누르면 참가자별 예상 이동시간을 조회합니다.

아직 선택한 역이 없어요.

대중교통 시간은 실제 열차 도착 시각을 보장하지 않는 API 경로 예상값입니다. 대중교통 REST API 사용을 위해 별도 Worker 설정이 필요합니다.
